Pour run le programme: cargo run


Pour modif la map dans le main:

MURS:
"DW"  => Mur double,
"W"   => Mur west,
"E"     => mur est,
"N1"  => Mur nord design 1,
"N2"    => Mur nord design 2,
"S"     => Mur sud,
"SW"    => mur angle sud west,
"SE"    => mur angle sud est,
"S5"    => mur nord angle est ou ouest je sais plus,
"S4"    => mur nord angle est ou ouest je sais plus,

PORTES:
"D"     => porte face,
"Dr"    => porte face symetrie,
"DL1"   => Porte laterale,
"DL2"   => Porte laterale symetrie,
"DO1"   => Porte ouverte (une porte mais on desactive les collisions),
"DO2"   => Porte ouverte (une porte mais on desactive les collisions),

SOLS:
"F1"    => sol design 1,
"F2"    => sol design 2,
"F3"    => sol design 3,
"F4"    => sol design 4,
"F5"    => sol design 5,
"F6"    => sol design 6,
"F7"    => sol design 7,
"F8"    => sol design 8,

DECOS:
"."     => Vide,
"T"     => Torche sur mur nord,
"Sk"    => crane,
"Chest" => coffre,
"Sp2"   => Toile d'araignee 1,
"Sp1"   => Toile d'araignee 2,
"Pot"   => Potion,
